PROFESSOR OI: APNA BROKER CONNECT KARO (LIVE DATA)
==================================================

Sabse aasaan tarika (3 step)
----------------------------
1. "Start-Live-Broker.bat" (Windows) ya "Start-Live-Broker.command" (Mac)
   par double-click karo. Browser mein Professor OI khulega:
       http://127.0.0.1:8765

2. "Broker & Data" page par apne broker ke card par "Connect" dabao.
   Ek form khulega jo SIRF wahi details maangega jo us broker ko chahiye.
   Bharo aur "Save & connect" dabao.

3. Kuch brokers (Kite, Upstox, Fyers, ICICI) apna login page kholenge:
   wahan login karo, apne aap wapas aa jaoge. Dhan (token) aur Angel
   khud login ho jaate hain. "Live Chain" page asli data se bhar jayega.

Pehli baar se pehle: Python 3.12 install karo  https://www.python.org/downloads/
(Windows par setup mein "Add python.exe to PATH" par tick zaroor lagao.)
Kuch aur install nahi karna.

Bina keys ke try karna ho: Broker page par "Try demo (no keys)" dabao.


Aapki details kahan jaati hain?
-------------------------------
Form ki details sirf aapke PC par chal rahe connector ko jaati hain
(127.0.0.1) aur wahin connector\config.json mein save hoti hain.
Page unhe dobara kabhi nahi padhta; form mein sirf "Saved" dikhta hai.

  !!  config.json kisi ko mat bhejo. Keys kisi chat mein (Claude bhi) paste mat karo.
  !!  Galti se share ho jaye to broker ki site par turant naya secret banao.


Har broker ke liye kya chahiye
==============================

Dhan  (sabse aasaan)
--------------------
Form mein "Access token (easiest)" chuno:
- Dhan Client ID:  web.dhan.co par profile mein dikhta hai
- Access token:    web.dhan.co -> My Profile -> Access DhanHQ APIs ->
                   "Generate Access Token" -> copy
- Save & connect dabao. Connector khud login karega.
- Token lagbhag ek din chalta hai. Agle din naya token banao, card par
  "Connect" dabao, naya token paste karke Save & connect.
API key + secret hai? Form mein "API key + secret" chuno, dono bharo, aur
Dhan app mein Redirect URL  http://127.0.0.1:8765/callback  rakho.
Note: Dhan option chain API 3 second mein 1 request deta hai, isliye update
thoda dheere aata hai. Option chain ke liye Dhan Data API plan active hona chahiye.

Zerodha Kite Connect
--------------------
- https://developers.kite.trade -> Create new app (Connect)
- App mein Redirect URL:  http://127.0.0.1:8765/callback
- Form mein: API key, API secret -> Save & connect -> Kite login page -> wapas.
- Kite Connect paid plan hai (site par price check karo).
- Kite pichhle din ka OI nahi bhejta, isliye OI change connector ke start se
  gina jaata hai. Pura din chahiye to 09:15 se pehle chalao.

Upstox
------
- https://account.upstox.com/developer/apps -> New app
- Redirect URL:  http://127.0.0.1:8765/callback  (bilkul same)
- Form mein: API key, API secret -> Save & connect -> Upstox login -> wapas.

Fyers
-----
- https://myapi.fyers.in/dashboard -> Create app  (App ID: XXXXXXXX-100)
- Redirect URL:  http://127.0.0.1:8765/callback
- Form mein: App ID, Secret key -> Save & connect -> Fyers login -> wapas.

Angel One SmartAPI
------------------
- https://smartapi.angelone.in -> My Apps -> Create app (Market Feeds API)
- Redirect URL ki zaroorat nahi.
- Form mein: API key, Client ID, MPIN (optional), TOTP secret key (optional)
  TOTP secret key = https://smartapi.angelone.in/enable-totp par QR code ke
  neeche jo text key dikhti hai.
- MPIN / TOTP key khaali chhodoge to har login par page 6 digit TOTP maangega.
- Pehli baar Angel ki badi instrument list download hoti hai (1 minute tak).

ICICI Direct Breeze
-------------------
- https://api.icicidirect.com/apiuser/home -> Register an app
- Redirect URL:  http://127.0.0.1:8765/callback
- Form mein: API key, API secret -> Save & connect -> ICICI login -> wapas.
- NIFTY aur BANKNIFTY aate hain.


Roz subah
---------
Start-Live-Broker chalao. Dhan/Angel khud connect ho jaate hain (Dhan ka
token roz naya). Baaki brokers ke liye Broker page par "Login with ..." dabao.
Broker badalna ho: kisi aur broker ke card par Connect dabao.


Broker kisi aur page par le gaya?
---------------------------------
Agar broker app mein pehle se koi aur Redirect URL saved hai, to login ke
baad wahi page khulega. Us page ke address bar ka POORA address copy karo,
Broker page par "Broker kisi aur page par le gaya?" kholo, paste karo, Connect.
(Upstox/Fyers ke liye config.json mein "redirect_url" bhi wahi likhna hoga.)


Dikkat aaye to
--------------
- Broker page par jo laal message dikhe, wahi asli wajah hai.
- "Port 8765 is busy": connector pehle se chal raha hai. Stop-Professor-OI.bat
  chalao ya purani kaali window band karo, phir dobara start karo.
- "Login expired": roz ka login khatam. "Login with ..." dobara dabao
  (Dhan: naya token daalo).
- "SSL certificate" error (Mac): Python folder mein "Install Certificates.command".
- Galat keys: card par Connect dabao, sahi keys daalo, Save & connect.

Abhi kya live hai: "Live Chain" page (NIFTY, BANKNIFTY ki asli chain: OI,
OI change, IV, buildup, max pain, PCR, din bhar ka chart), header ka ticker
aur Broker page ke live ticks. Baaki pages abhi demo data par hain.

Ye tool sirf analysis ke liye hai, trading advice nahi.
